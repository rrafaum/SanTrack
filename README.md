# SanTrack

> Uma plataforma de acompanhamento de progresso para completar 100%
do Grand Theft Auto: San Andreas clássico.

## Sobre

O **SanTrack** é um projeto desenvolvido para jogadores que desejam
completar 100% do **Grand Theft Auto: San Andreas clássico** e
procuram uma forma organizada, visual e interativa de acompanhar sua
evolução durante essa jornada.

A proposta é centralizar os diferentes objetivos necessários para a
conclusão do jogo — como missões, atividades, coletáveis e outros
requisitos — permitindo registrar o que já foi concluído, visualizar
o que ainda falta e acompanhar o progresso geral.

O projeto nasceu de uma necessidade percebida durante uma experiência
pessoal de completar novamente o GTA San Andreas: embora existam
diversos guias, vídeos e materiais explicando como alcançar 100%, eles
são geralmente voltados para instrução, e não para o acompanhamento
individual do progresso do jogador.

O SanTrack busca preencher essa lacuna.


## Objetivo

Criar uma experiência de acompanhamento de progresso para o GTA San Andreas
clássico como se o jogo tivesse sido originalmente lançado com um sistema
moderno de progresso, conquistas, estatísticas e gerenciamento de objetivos.

O projeto será desenvolvido de forma incremental, começando como uma
aplicação web simples e evoluindo gradualmente conforme novas
necessidades e tecnologias forem incorporadas.


## Estado atual

🚧 **Em desenvolvimento — fase de planejamento.**

O SanTrack encontra-se atualmente na etapa de definição e planejamento
do produto. A implementação da aplicação ainda não foi iniciada.

O desenvolvimento seguirá uma abordagem incremental, começando por uma
versão simples e independente e evoluindo posteriormente para
funcionalidades mais avançadas.


## Funcionalidades planejadas

Entre as funcionalidades previstas para a evolução do SanTrack estão:

* Acompanhamento das missões do jogo;
* Acompanhamento de atividades e missões secundárias;
* Acompanhamento de coletáveis;
* Registro de progresso;
* Cálculo e visualização do progresso geral;
* Detalhamento dos objetivos;
* Mapa interativo;
* Filtros e categorias de conteúdo;
* Estatísticas de progresso;
* Checkpoints e metas de progresso;
* Temas claro e escuro;
* Suporte a múltiplos idiomas;
* Conta de usuário;
* Persistência e sincronização do progresso;
* Integração futura com o jogo por meio de um mod.

> As funcionalidades acima representam a visão de evolução do projeto e
não significam que todas estarão presentes na primeira versão.


## Tecnologias

A primeira versão do SanTrack será desenvolvida utilizando tecnologias
fundamentais da web:

* HTML;
* CSS;
* JavaScript.

Conforme o projeto evoluir, novas tecnologias poderão ser incorporadas,
incluindo:

* React;
* TypeScript;
* Backend;
* API;
* Banco de dados;
* Autenticação;
* Outras ferramentas e tecnologias que se mostrarem adequadas às
necessidades do projeto.

A escolha e adoção de cada tecnologia será feita de forma incremental,
evitando complexidade desnecessária nas primeiras versões.
